# História: chat e comparação de Router

Versão 1 — 2026-10-27. Avaliador sintético entra como demo, identifica o modo simulado,
escolhe perfil e envia uma mensagem. Continua a conversa e inspeciona fontes/modelos.
Compara LLM/JEV e usa a decisão selecionada no atendimento uma única vez. Atualiza a
tela sem reenvio. Tenta publicar como demo e recebe recusa; admin pode publicar uma
versão compatível. JEV indisponível gera erro explícito, sem fallback silencioso.

Candidato e evidências ainda pendentes. Percorrer via Streamlit/HTTP; AppTest não
substitui evidência real do JEV. Verificar sessão expirada, backend indisponível,
configuração incompatível, acesso de outro dono e modos real/simulado/gravado.
O QA registra fatos observados e limitações, sem alterar o produto para aprovação.
