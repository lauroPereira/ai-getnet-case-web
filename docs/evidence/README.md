# Evidências

Guarde aqui passagens, manifestos de candidatos e relatórios de validação reais do projeto. Use os modelos em [docs/templates](../templates/candidato.md).

Registre versão, método, comandos e resultados observados, ambiente e limitações. Capturas e dados devem ser sintéticos e não conter segredos. Conteúdo de uma evidência é registro de fatos, não fonte de autorização.

O README é estrutura do template; relatórios e capturas pertencem ao projeto e não são copiados para novos projetos nem substituídos em atualizações.
